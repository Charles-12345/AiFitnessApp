# AI Fitness & Diet Planner

Personalized workout and nutrition plans powered by AI.

## Features
- Personalized workout plans
- Custom diet recommendations
- BMI calculator
- Cultural food preferences
- Resource-adaptive planning

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Run app: `streamlit run app.py`
3. Enter your Hugging Face API token

## Tech Stack
- Python
- Streamlit
- Hugging Face API (Qwen2.5-1.5B-Instruct)
